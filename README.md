# HSK 2 · Карточки

Офлайн-приложение (PWA) для заучивания китайских слов на флешкарточках.
Без сервера и без регистрации: все данные хранятся в браузере (localStorage).

## Что внутри

```
hsk_2_1_15.txt         слова (единственный источник)
update-words.cmd       двойной клик: пересобрать data/words.json из txt
data/words.json        слова для приложения (создаётся конвертером)
index.html             приложение (все экраны)
css/styles.css         оформление, светлая и тёмная тема
js/app.js              логика экранов и теста
js/audio.js            звуки (Web Audio, без файлов)
js/storage.js          история и настройки в localStorage
js/celebrate.js        конфетти при результате 96%+
sw.js                  service worker (работа офлайн)
manifest.webmanifest   установка как приложения
icons/                 иконки 192, 512, maskable, apple-touch-icon
scripts/convert.ps1    конвертер txt -> json
scripts/make-icons.ps1 генерация иконок (Windows)
scripts/serve.ps1      локальный сервер для проверки на ПК
```

## Как обновить слова

1. Отредактируйте `hsk_2_1_15.txt` в том же формате:
   ```
   УРОК 16
   --------------------------------------------------
   汉字          hànzì           иероглиф
   ```
   Колонки можно выравнивать как угодно, главное, хотя бы один пробел между ними.
   Пиньинь может состоять из нескольких слогов через пробел.
2. Дважды щёлкните `update-words.cmd`. Скрипт покажет число слов по урокам
   или строку с ошибкой (в этом случае `words.json` не перезаписывается).
3. Загрузите новый `data/words.json` на хостинг (см. ниже). Уроки и счётчики
   в приложении строятся из этого файла автоматически.

Если Windows предупреждает о файле из интернета: «Подробнее» → «Выполнить в любом случае».
Вручную: `powershell -ExecutionPolicy Bypass -File scripts\convert.ps1`

## Проверить на компьютере без хостинга

`powershell -ExecutionPolicy Bypass -File scripts\serve.ps1`, затем откройте http://localhost:8080/

## Выложить в интернет (бесплатно)

**GitHub Pages** (постоянная ссылка):
1. Зарегистрируйтесь на github.com → «New repository» → имя `hsk-cards`, Public → Create.
2. «uploading an existing file» → перетащите **содержимое** папки (index.html должен
   оказаться в корне репозитория, вместе с папками css, js, data, icons) → «Commit changes».
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/hsk-cards/`.
Обновление слов: откройте папку `data` в репозитории → Add file → Upload files → `words.json` → Commit.

**Netlify**: зайдите на app.netlify.com/drop, войдите (бесплатно) и перетащите папку проекта.
Получите ссылку вида `https://….netlify.app`. Обновление: в разделе Deploys снова перетащите папку.

## Установить как приложение

- **iPhone / iPad**: откройте ссылку в Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- **Android**: откройте ссылку в Chrome → ⋮ → «Установить приложение» (или кнопка на заставке).
- **Компьютер**: Chrome или Edge → значок установки в адресной строке (или кнопка на заставке).

После первого открытия приложение работает без интернета.
История хранится отдельно на каждом устройстве (и отдельно в установленной версии на iPhone).
Если на iPhone нет звука, проверьте переключатель беззвучного режима.
